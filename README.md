# Digital Data Transmission Error Detection Using XOR Logic

This is a Group 11 DDCA course project that demonstrates error
detection in digital data transmission using XOR-based parity checking.

## Repository Details

- Section: 14
- Batch: 11
- Course: DDCA
- Repository: KLH-FED-2026-14-11

## Objective

To design and simulate a digital circuit that detects single-bit
transmission errors using XOR logic.

## Working Principle

The transmitter uses XOR gates to generate a parity bit. The receiver
performs the XOR operation again on the received data and parity bit.

- Output 0: No error detected
- Output 1: Error detected

## Limitation

XOR parity can detect single-bit errors but may not detect an even
number of simultaneous bit errors.
